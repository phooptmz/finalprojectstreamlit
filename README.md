# AI Smart Air Conditioning System

ระบบควบคุมการทำงานของเครื่องปรับอากาศอัจฉริยะแบบเรียลไทม์ ทำงานแบบรวมศูนย์บนคอมพิวเตอร์กระดานเดี่ยว (Raspberry Pi 5) ผ่าน Web Dashboard ที่พัฒนาด้วย Streamlit ระบบนี้มุ่งเน้นการเพิ่มประสิทธิภาพการใช้พลังงานและรักษาระดับความสบายทางความร้อนภายในอาคาร โดยผสานรวมเทคโนโลยี Computer Vision สำหรับประมวลผลวิดีโอเพื่อตรวจจับบุคคลและการเคลื่อนไหว, Machine Learning สำหรับทำนายอุณหภูมิที่เหมาะสม และเชื่อมต่อกับฮาร์ดแวร์ IoT เพื่ออ่านค่าสภาพแวดล้อมและสั่งการเครื่องปรับอากาศอัตโนมัติ

## สถาปัตยกรรมฮาร์ดแวร์ (Hardware Architecture)

* **หน่วยประมวลผลหลัก** Raspberry Pi 5 ทำหน้าที่เป็นศูนย์กลางรันระบบประมวลผลและเว็บแอปพลิเคชัน
* **หน่วยรับภาพวิดีโอ** กล้องวงจรปิดไอพีแบบเลนส์คู่ (Dual-lens) รุ่น FNKvision DAX23 สตรีมภาพผ่านโปรโตคอล RTSP
* **หน่วยควบคุมอินฟราเรด** BroadLink RM4 mini ทำหน้าที่เป็นสะพานเชื่อมแปลงคำสั่งดิจิทัลเป็นสัญญาณอินฟราเรด (IR)
* **หน่วยตรวจวัดสภาพแวดล้อม** สายเคเบิลเซนเซอร์รุ่น HTS2 สำหรับดึงข้อมูลอุณหภูมิและความชื้นสัมพัทธ์แบบเรียลไทม์

## คุณสมบัติหลัก (Key Features)

* **Real-Time Dual-Lens Tracking** ตรวจจับและติดตามบุคคล (Person Tracking) ผ่านกล้องเลนส์คู่ด้วยโมเดล YOLO (v8 หรือ v11) 
* **Occupancy Comfort Index (OCI)** อัลกอริทึมคำนวณดัชนีบริบทการใช้งานพื้นที่แบบไดนามิก โดยพิจารณาจากจำนวนคนเฉลี่ย ระดับการทำกิจกรรม (ระยะกระจัด) และความต่อเนื่องในการใช้งานพื้นที่
* **AI Temperature Prediction** ใช้แบบจำลองเรียนรู้ของเครื่องประเภทการจำแนกกลุ่ม (LightGBM) วิเคราะห์ค่า OCI ร่วมกับอุณหภูมิและความชื้นปัจจุบัน เพื่อทำนายและกำหนดอุณหภูมิเป้าหมายที่เหมาะสมที่สุด (23°C, 25°C หรือ 28°C)
* **Energy Optimization (Auto-Close / Auto-Resume)** ระบบสั่งปิดเครื่องปรับอากาศอัตโนมัติเมื่อไม่มีคนอยู่ในพื้นที่ตามระยะเวลาที่กำหนดเพื่อประหยัดพลังงาน และเปิดกลับเป็นโหมด Auto ทันทีเมื่อตรวจพบการใช้งานพื้นที่
* **Hardware Integration** ระบบสแกนและเชื่อมต่ออุปกรณ์ BroadLink ในเครือข่ายอัตโนมัติ เพื่อส่งสัญญาณ IR ไปยังเครื่องปรับอากาศโดยไม่ต้องใช้มนุษย์ควบคุม
* **Resource Management** จัดการทรัพยากรระบบด้วยการเขียนโปรแกรมแบบมัลติเธรด (Multi-threading) เพื่อป้องกันความหน่วงในการสตรีมภาพ และมีการคืนพื้นที่หน่วยความจำ (Garbage Collection) ส่วนที่ไม่ได้ใช้งานทุก 10 วินาทีเพื่อป้องกันระบบขัดข้อง

## กระบวนการทำงานของระบบ (System Workflow)

ระบบแบ่งการทำงานออกเป็นส่วนต่างๆ เพื่อให้การแสดงผล UI และการประมวลผลทำงานได้อย่างราบรื่น

1. **Background Device Scanner** สแกนหา IP Camera (พอร์ต RTSP) และ BroadLink RM4 mini ในเครือข่ายวงแลน (192.168.1.xxx) เมื่อพบอุปกรณ์ ระบบจะทำการเชื่อมต่อและดึงข้อมูลอุณหภูมิและความชื้นสัมพัทธ์เริ่มต้นทันที
2. **Video Capture & Processing** รับภาพจากกล้องผ่านโปรโตคอล RTSP โดยใช้ Thread แยกเพื่อลด Latency ภาพจะถูกย่อขนาดและส่งเข้าโมเดล YOLO เพื่อตรวจจับบุคคล พร้อม Custom Tracker ที่จำแนกการเดินข้ามระหว่าง "เลนส์บน" และ "เลนส์ล่าง" ของกล้อง เพื่อป้องกันการนับจำนวนคนซ้ำซ้อน
3. **OCI Calculation** คำนวณ N (จำนวนคนเฉลี่ย), A (ระยะกระจัด/การเคลื่อนไหว), และ P (การมีอยู่ของคน) จากนั้นนำมาถ่วงน้ำหนักเพื่อสร้างเป็นค่า OCI และ Delta OCI
4. **AI Decision Engine** ในโหมด Auto ทุกๆ 60 วินาที ระบบจะนำข้อมูล `[OCI, Delta_OCI, อุณหภูมิในห้อง, ความชื้นในห้อง]` ส่งเข้าโมเดล LightGBM เพื่อทำนายคลาสอุณหภูมิเป้าหมาย
5. **IR Command Execution** ส่งคำสั่งควบคุมผ่าน API ของ BroadLink ไปยังเครื่องปรับอากาศ พร้อมระบบ Auto-Close Delay ที่จะนับถอยหลังและยิงคำสั่งปิดการทำงานทันทีหากไม่พบผู้ใช้งานต่อเนื่องตามเวลาที่กำหนด

## ความต้องการของระบบ (Prerequisites)

* **ซอฟต์แวร์** Python 3.9 หรือใหม่กว่า
* **ฮาร์ดแวร์**
  * คอมพิวเตอร์หรือบอร์ด Raspberry Pi 5
  * กล้อง IP Camera ที่รองรับ RTSP แบบ Dual-lens (เช่น FNKvision DAX23)
  * อุปกรณ์ BroadLink RM4 Pro หรือ Mini พร้อมเซนเซอร์ HTS2
  * เครื่องปรับอากาศที่รองรับการสั่งงานด้วยรีโมทอินฟราเรด (IR)
* **ไฟล์โมเดลและข้อมูล**
  * โมเดล YOLO `yolov8n.pt` หรือ `yolo11n.pt` (รองรับไฟล์ `.onnx` หากตั้งค่า `USE_ONNX = True`)
  * โมเดล AI `LightGBM_model.joblib`
  * โฟลเดอร์ `ircode` ที่บรรจุไฟล์คำสั่งฐานสอง `.bin` (เช่น `23.bin`, `25.bin`, `close.bin`)

## การเริ่มต้นใช้งาน (Getting Started)

**1. โคลนพื้นที่จัดเก็บ (Clone Repository)**
```bash
git clone [https://github.com/phooptmz/finalprojectstreamlit.git](https://github.com/phooptmz/finalprojectstreamlit.git)
cd finalprojectstreamlit

```

**2. ติดตั้ง Dependencies**

```bash
pip install -r requirements.txt

```

**3. การตั้งค่าก่อนใช้งาน**
ตรวจสอบการตั้งค่าในส่วน Configuration ของไฟล์โค้ดหลัก (`finalcode.py`)

* เปลี่ยน `IS_RASPBERRY_PI = True` เมื่อนำไปรันบนบอร์ด Raspberry Pi
* ปรับ `TARGET_FPS` ให้เหมาะสมกับทรัพยากรเครื่อง

**4. รันระบบ**

```bash
streamlit run finalcode.py

```
